# 👨‍💻 Object-Oriented Programming in C++

Welcome to my repository dedicated to **Object-Oriented Programming (OOP) in C++**! 🚀  
This project is the result of my personal study and exploration of the core OOP principles using modern C++.

---

## 📚 What I Learned

Throughout this journey, I aimed to cover **all the major pillars of OOP** and their implementation in C++:

### 🌟 OOP Principles

- **Encapsulation** – Hiding internal state and exposing only necessary interfaces
- **Abstraction** – Defining clear and simplified models of real-world concepts
- **Inheritance** – Reusing code and extending existing functionality
- **Polymorphism** – Achieving flexibility through function overloading and overriding

---

## 🧱 Core Concepts Practiced

- ✅ **Classes** and **Objects** – The building blocks of OOP in C++
- 🛠️ **Constructors** and **Destructors** – Managing object lifecycle
- 🔒 **Access Modifiers** – `public`, `private`, `protected`
- ➕ **Operator Overloading** – Making custom types intuitive to use
- ⚙️ **Lambda Functions** – Writing inline, anonymous functions for flexibility
- 🧬 **Function Overloading** and **Overriding**
- 🌐 **Static Members** and **Friend Functions**
- 📦 **Header Files and Code Organization**
- 🔁 **Composition vs Inheritance**
